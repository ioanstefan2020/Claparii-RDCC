# Plan: P1 — T1.1 Skeleton (FastAPI Backend + Guardrails + Mock LLM)

## Goal
Build the initial FastAPI skeleton for P1 per `docs/CONTRACTS.md` §2 and `docs/TASKS.md` T1.1 so teammates P2 and P3 can immediately run against mock data or build their routers.

## Files Owned and Touched
- `app/main.py`: FastAPI app, auto-discovery of routers from `app/routers/`, static mounting of `web/` if it exists, error envelope handlers, `/api/health`.
- `app/config.py`: Environment configuration via `pydantic_settings` or standard env parsing (`LOG_CONTENT`, `LLM_PROVIDER`, `LLM_CACHE_DIR`, `MAX_INPUT_CHARS`, etc.).
- `app/guardrails.py`: `verify_quotes(items, source_text, key="source_quote")` whitespace-normalised substring check.
- `app/llm/__init__.py`: `generate_json(task, system, user, schema, mock)` with mock provider and disk cache.
- `app/schemas/common.py`: Error envelope, success envelope, error response helpers, and exception types (`LLMUnavailable`, `BadLLMOutput`, `AppError`).
- `tests/backend/test_health.py`: `GET /api/health` returns `{"ok": true, "provider": "mock"}` and error handling tests.
- `tests/backend/test_guardrails.py`: Verifies `verify_quotes` keeps matching quotes and drops fabricated quotes.
- `tests/backend/test_llm.py`: Tests `generate_json` with mock provider, disk cache hit/miss, and validation.

## Acceptance Criteria
- `python3 -m pytest -q` passes all backend tests and static a11y test.
- `./scripts/check.sh` exits 0.
- `uvicorn app.main:app` starts, `curl -s http://127.0.0.1:8000/api/health` returns `{"ok": true, "provider": "mock"}`.
- All touched files are owned by `p1` according to `OWNERS`.
