## Feature: T1.6 Safety and robustness layer

**Goal:** Implement `app/safety.py` and comprehensive tests in `tests/backend/test_safety.py` to enforce responsible AI standards: strict zero content logging when `LOG_CONTENT=false` (GDPR compliance), prompt-injection mitigation across all sample vectors, `NO_CACHE=1` confidential handling, and user input bounds checking.
**Non-goals:** Storing user documents; implementing diagnosis classification.
**Design:**

- `app/safety.py`:
  - `sanitize_log_message(msg: str, user_content: str | None = None) -> str`: Ensures no document or transcript text leaks into logs.
  - `contains_prompt_injection(text: str) -> bool`: Heuristic detection of common injection payloads ("ignore previous instructions", "system override", "jailbreak").
  - `validate_input_limits(text: str, max_chars: int) -> str`: Centralized bounds checker raising `AppError("empty_input" / "too_long")`.
  - `DENY_DIAGNOSIS_TERMS`: Comprehensive set of medical/diagnostic keywords (ADHD, autism, schizofrenie, handicap, retard, etc.) to ensure no diagnostic labeling in outputs.
- `tests/backend/test_safety.py`:
  - Test verifying logs contain no document contents when processing requests.
  - Test verifying `NO_CACHE=1` writes zero files to `LLM_CACHE_DIR`.
  - Test verifying prompt-injection samples (like `injection_ro.txt`) fail to breach schema or inject unauthorized commands.
  - Test verifying medical/diagnostic term filtering.
    **Interfaces:**
- Functions in `app/safety.py`: `validate_input_limits`, `contains_prompt_injection`, `sanitize_log_message`, `contains_diagnosis_terms`.
  **Tasks:**
- [x] T1 (owns: `app/safety.py`) — Implement safety and sanitization utilities.
- [x] T2 (owns: `tests/backend/test_safety.py`) — Write regression tests covering logging privacy, cache control, injection resistance, and diagnostic vocabulary deny-list.
      **Acceptance criteria:**

1. Tests pass: `python3 -m pytest tests/backend/test_safety.py` passes.
2. Gate passes: `./scripts/check.sh` exits 0.
3. Zero privacy leaks verified in logs and cache.
