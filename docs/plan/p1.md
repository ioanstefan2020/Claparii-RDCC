## Feature: T1.2 Real Providers + Romanian Bake-off

**Goal:** Implement Gemini and DeepSeek via `httpx` with timeout, 1-retry on invalid JSON, error mapping to `LLMUnavailable`/`BadLLMOutput`, and bake-off test harness for Romanian samples.
**Non-goals:** Endpoints implementation (owned by T1.3–T1.5); persistent secret storage (keys passed via env vars); diagnosis logging.
**Design:**

- `app/llm/providers/base.py`: Abstract provider interface.
- `app/llm/providers/gemini.py`: Direct Google Gemini REST API call via `httpx` with JSON schema enforcement.
- `app/llm/providers/deepseek.py`: DeepSeek OpenAI-compatible chat completions API via `httpx` with JSON response mode.
- `app/llm/__init__.py`: Wire `generate_json` to select provider from config (`mock`, `gemini`, `deepseek`) with 1-retry fallback.
- `tests/backend/test_providers.py`: Mocked HTTP tests verifying error mapping (`LLMUnavailable`, `BadLLMOutput`), timeout handling, and retry logic.
- `tests/eval/test_bakeoff.py`: Live bake-off evaluation script runnable with `pytest -m live` comparing quote fidelity and Romanian output.
  **Interfaces:**
- `call_provider(provider_name: str, system: str, user: str, schema: type[BaseModel]) -> dict`
  **Tasks:**
- [x] T1 (owns: `app/llm/providers/**`, `app/llm/__init__.py`) — Implement base provider, Gemini, DeepSeek, and retry dispatch.
- [x] T2 (owns: `tests/backend/test_providers.py`) — Unit test provider error mappings and retry behavior with mocked HTTP responses.
- [x] T3 (owns: `tests/eval/**`, `docs/decisions/p1.md`) — Bake-off runner comparing Romanian samples and recording default provider choice.
      **Acceptance criteria:**

1. Unit tests pass: `python3 -m pytest tests/backend/test_providers.py`
2. Gate passes: `./scripts/check.sh` exits 0.
3. Decision documented: `docs/decisions/p1.md` notes tested providers and fallback logic.
