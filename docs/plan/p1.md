## Feature: T1.4 /api/plan/extract

**Goal:** Implement `POST /api/plan/extract` extracting structured tasks with deadlines from workplace documents, emails, or instructions into actionable items with verbatim source quotes, safely resolving relative dates with `today_iso`, and strictly flagging vague/ambiguous deadlines (`due_iso=null`, `needs_confirmation=true`) without hallucinating dates.
**Non-goals:** Calendar rendering or `.ics` generation (owned by P2 client-side in `ics.js` / T2.4); storing user plans on server.
