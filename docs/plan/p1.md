## Feature: T1.3 /api/simplify

**Goal:** Implement `POST /api/simplify` converting complex workplace documents (onboarding, emails, procedures) into plain Romanian summaries, numbered steps with verbatim `source_quote`s, explained key terms, and suggested clarification questions according to user profile.
**Non-goals:** Audio playback (handled client-side by P2); persisting user documents; extracting deadlines/tasks into planner (that's T1.4).
**Design:**

- `app/schemas/simplify.py`: Profile, StepItem, KeyTermItem, SimplifyData, SimplifyRequest models matching CONTRACTS §1 and §3.1.
- `app/prompts/simplify.py`: SYSTEM prompt (treats doc as untrusted data, plain Romanian, profile-aware, no diagnosis/emotion), `build_user(text, profile)`, and MOCK fixture.
- `app/routers/simplify.py`: Endpoint `POST /api/simplify` validating inputs (`MAX_INPUT_CHARS`, empty trim check), invoking `generate_json`, applying `verify_quotes` to steps, adding `meta.warnings` for dropped fabricated quotes, returning `SuccessEnvelope[SimplifyData]`.
- `tests/backend/test_simplify.py`: Tests for contract shape, empty input (`empty_input`), too long (`too_long`), guardrail dropping fabricated quotes with warning, prompt injection resistance, and mock provider integration.
  **Interfaces:**
- CONTRACTS §3.1: `POST /api/simplify` -> `{"ok": true, "data": {"summary": str, "steps": list[StepItem], "key_terms": list[KeyTermItem], "questions_to_ask": list[str]}, "meta": {...}}`
  **Tasks:**
- [x] T1 (owns: `app/schemas/simplify.py`) — Define Pydantic request & response schemas.
- [x] T2 (owns: `app/prompts/simplify.py`) — Write Romanian plain-language prompt treating document as untrusted data + mock fixture.
- [x] T3 (owns: `app/routers/simplify.py`) — Implement router with auto-discovery, input validation, LLM call, and `verify_quotes` guardrail.
- [x] T4 (owns: `tests/backend/test_simplify.py`) — Test contract shape, input validation, fabricated quotes dropping, and prompt-injection resilience.
      **Acceptance criteria:**

1. Tests pass: `python3 -m pytest tests/backend/test_simplify.py` passes all test cases.
2. Gate passes: `./scripts/check.sh` exits 0.
3. Server curl: `curl -X POST http://127.0.0.1:8000/api/simplify` returns valid success envelope with mock provider.
