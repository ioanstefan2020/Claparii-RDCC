## Feature: N1.7 Request Metrics & Privacy-Safe Logging Middleware

**Goal:** Implement privacy-safe request logging middleware in `app/main.py` that measures endpoint latency, status codes, and failure rates while strictly redacting all user document texts from logs (`LOG_CONTENT=false`).
**Non-goals:** Storing user personal data or documents.
**Design:**

- Add an ASGI HTTP middleware in `app/main.py` recording start time, method, path, HTTP status, and duration (e.g. `[METRICS] POST /api/simplify -> 200 OK (0.12s)`).
- Never log query params or request bodies when `LOG_CONTENT=false` to prevent leaking sensitive documents or accommodation requests into terminal stdout/stderr.
- Unit test in `tests/backend/test_health.py` asserting metrics output format and headers.
