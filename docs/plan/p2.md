## Feature: Planner Screen (T2.4)

### 1. Goal & Non-goals
- **Goal:** Enable an employee to extract actionable tasks and deadlines from unstructured workplace texts (e.g. task emails, manager instructions, onboarding checklists) via `POST /api/plan/extract` (or `?mock=1` fixture fallback), review structured tasks with priorities and sub-steps, safely handle ambiguous deadlines ("cât mai repede", "până joi") with explicit warnings and manual date confirmation, edit/add/complete/delete tasks in local memory/storage, and download a valid RFC 5545 calendar `.ics` file.
- **Non-goals:** Server-side synchronization or cloud calendar account OAuth integration; inferring or guessing ambiguous deadlines without explicit user input; storing personal health data or diagnoses.

### 2. Interfaces & Contracts
- **Endpoint:** `POST /api/plan/extract` with `{ "text": "...", "today_iso": "YYYY-MM-DD", "profile": { ... } }`
- **Response Shape:**
  ```json
  {
    "ok": true,
    "data": {
      "tasks": [
        {
          "id": "t1",
          "title": "Completează formularul F-12",
          "due_iso": "2026-10-28",
          "due_text": "miercuri, 28 octombrie",
          "needs_confirmation": false,
          "priority": "high",
          "steps": ["Deschide portalul intern", "Completează datele personale și bancare"],
          "source_quote": "Până miercuri, 28 octombrie, trebuie să completezi în portalul intern formularul F-12"
        }
      ]
    },
    "meta": { "provider": "...", "cached": false, "warnings": [...], "ai_notice_ro": "..." }
  }
  ```
- **Client Storage:** `localStorage` key `primazi_planner_tasks`. Task item structure:
  `{ id, title, due_iso, due_text, needs_confirmation, priority, steps, source_quote, completed: boolean }`
- **ICS Integration:** `web/shared/ics.js` (`generateIcs(tasks)`, `downloadIcsFile(filename, icsContent)`). Tasks with `needs_confirmation: true` include `[De confirmat]` tag in summary and clear warning in description, and do not invent fake calendar dates.
- **Module Exports (`web/employee/plan.js`):**
  - `SAMPLE_TASK_EMAIL`
  - `loadStoredTasks()`, `saveStoredTasks(tasks)`, `clearStoredTasks()`
  - `addTask(tasks, newTask)`, `updateTask(tasks, id, updates)`, `deleteTask(tasks, id)`, `toggleTaskCompletion(tasks, id)`, `confirmTaskDate(tasks, id, dateIso)`
  - `formatDateRo(isoStr)`, `escapeHtml(str)`
  - `renderTasks(tasks, container, callbacks)`
  - `initPlanPage()`

## Feature: Clarify Screen (T2.3)

### 1. Goal & Non-goals
- **Goal:** Enable an employee to paste or upload an onboarding document / workplace instructions (`.txt`), optionally load realistic Romanian sample text with one click, submit it to `/api/simplify`, and receive a plain-Romanian summary with TTS read-aloud, numbered steps with interactive "Arată în text" source quote highlighting and scrolling, explained key terms, suggested questions for colleagues/manager, and guardrail warning notices.
- **Non-goals:** Parsing binary formats (.pdf, .docx) client-side; server-side document storage; collecting or inferring health/disability diagnoses; calendar task creation (delegated to T2.4 Planner via CTA link).

### 2. Interfaces & Contracts
- **Endpoint:** `POST /api/simplify` with `{ "text": "...", "profile": { ... } }`
- **Response:** `{ ok: true, data: { summary, steps: [{ n, text, source_quote }], key_terms: [{ term, explanation }], questions_to_ask: [...] }, meta: { provider, cached, warnings, ai_notice_ro } }`
- **Client Module (`web/employee/clarify.js`):**
  - Exports: `SAMPLE_ONBOARDING_TEXT`, `normalizeWhitespace(str)`, `highlightQuoteInContainer(container, fullText, quote)`, `renderWarnings`, `renderSummary`, `renderSteps`, `renderKeyTerms`, `renderQuestions`, `initClarifyPage`.
