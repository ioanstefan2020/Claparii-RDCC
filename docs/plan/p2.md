## Feature: Preferences Engine (N2.1)

### 1. Goal & Non-goals
- **Goal:**
  - Build a modular, browser-only Preferences Engine in `web/js/prefs/` translating user answers to plain-language comfort questions ("How do you like things?") into CSS-ready `data-*` attributes and UI comfort preferences.
  - Storage key `wp.prefs.v1` in `localStorage` with resilient in-memory fallback if storage throws (`QuotaExceededError`, `SecurityError` in private browsing, or storage disabled), never crashing.
  - Support manual user `overrides` that are strictly preserved during re-derivation.
  - Provide `resetToAnswers(state)` (clears overrides only, reapplies answers) and `resetAll()` (clears all to factory defaults).
  - Provide safe schema migration & corrupt payload recovery via `migrate(raw)`.
  - Provide DOM attribute applicator `applyPrefs(prefs, rootElement)` and FOUC (flash of unstyled content) prevention snippet via `getInlineHeadScript()`.
  - Ship comprehensive unit tests in `tests/web/prefs/test_prefs.mjs` (runnable with `node --test`) and a pytest bridge in `tests/web/test_prefs_node.py` integrated into `./scripts/check.sh`.
- **Non-goals:**
  - Asking for, storing, logging or inferring medical diagnoses, disabilities, or health conditions (strict compliance with AGENTS.md §1 & §11).
  - Emotion inference from voice, face, or responses (EU AI Act compliance).
  - Sending preference data or answers to the backend server (100% private, client-side only).
  - Building questionnaire UI or DOM screens (owned by P3 in N3.1 & N3.3; P2 provides pure logic + tests).
  - Adding external npm dependencies (pure vanilla ES modules and standard Node.js test runner).

### 2. Architecture & Design
- Public module: `web/js/prefs/index.js`
- Submodules:
  - `web/js/prefs/types.js` (constants, schemas, defaults)
  - `web/js/prefs/derive.js` (`derivePrefs(answers, currentPrefs, overrides)`)
  - `web/js/prefs/migrate.js` (`migrate(raw)`, `resetToAnswers(state)`, `resetAll()`)
  - `web/js/prefs/storage.js` (`loadPrefs()`, `savePrefs(state)`, in-memory fallback, export/import JSON)
  - `web/js/prefs/apply.js` (`applyPrefs(prefs, rootElement)`, `getInlineHeadScript()`)
