### 2. Multi-Dimensional Verification Matrix

#### Dimension 1: Keyboard Traversal & Focus Management (WCAG 2.1.1, 2.1.2, 2.4.3, 2.4.7)
- [x] **Skip to Main Content Link (`.skip-link`):** Present on every single route as the first focusable element. Pressing `Tab` upon initial page load immediately brings the skip link into view; pressing `Enter` moves keyboard focus directly to `<main id="main">`.
- [x] **Tab Order Predictability:** Focus flows strictly logically from top to bottom, left to right. Zero positive `tabindex` attributes anywhere across the codebase.
- [x] **High-Contrast Visible Focus Rings:** Every interactive element (`<a>`, `<button>`, `<input>`, `<select>`, `<textarea>`) displays a distinct 3px outline with minimum 3:1 contrast against both element background and adjacent surfaces.
- [x] **No Keyboard Traps:** Modals, collapsible drawers, and dropdowns can be escaped cleanly using standard keys (`Escape`, `Tab`, `Shift+Tab`).
- [x] **Active Control Execution:** All primary buttons respond cleanly to `Enter` and `Space`.

#### Dimension 2: 200% Zoom & 320px Responsive Reflow (WCAG 1.4.4, 1.4.10)
- [x] **Viewport Scalability:** Every route specifies `<meta name="viewport" content="width=device-width, initial-scale=1">` without restricting `maximum-scale` or setting `user-scalable=no`.
- [x] **Text Scaling at 200%:** Zooming browser viewport to 200% on standard 1080p display causes zero truncation of text, zero overlapping containers, and zero horizontal scrolling on body content.
- [x] **320px Mobile Reflow:** Multi-column grids (such as the `/welcome.html` split wizard, `/employee/plan.html` task inputs, and `/employer/index.html` metric cards) wrap cleanly into a single vertical column. The collapsible sidebar becomes a sliding drawer opened via an accessible `button[aria-label="Deschide meniul de navigare"]`.

#### Dimension 3: Screen Reader Verification (NVDA, VoiceOver, Orca) (WCAG 1.3.1, 4.1.2, 4.1.3)
- [x] **Page Language (`lang="ro"`):** Stamped on the root `<html>` element of every served route, ensuring speech engines load Romanian phonetic dictionaries.
- [x] **Single `<h1>` Semantic Hierarchy:** Every page contains exactly one `<h1>` header clearly designating the screen's purpose, followed by logical `<h2>` and `<h3>` section landmarks.
- [x] **Form Controls & Label Association:** Every input, textarea, and select element is explicitly associated with a `<label for="...">` or carries an unambiguous `aria-label`/`aria-labelledby`.
- [x] **Live Region Feedback (`aria-live="polite"`):** Every page includes an `#status-live` live region. Asynchronous operations (document analysis, planning extraction, adjustment drafting) announce status changes to screen readers without stealing keyboard focus.
- [x] **Decorative Icons Hidden:** All visual SVG icons carry `aria-hidden="true"`, preventing screen readers from reading meaningless vector path sequences.

#### Dimension 4: High-Contrast & Dark Mode Matrix (WCAG 1.4.3, 1.4.6, 1.4.11)
- [x] **Light Mode Contrast:** Body text (`#111827` on `#ffffff`) delivers 17.7:1 contrast ratio; muted meta text (`#374151` on `#ffffff`) delivers 10.3:1 (exceeding WCAG 2.2 AA requirement of 4.5:1).
- [x] **Dark Mode Contrast:** Body text delivers >= 11.5:1 contrast against dark slate background surfaces.
- [x] **High-Contrast Theme (WCAG AAA):** Yellow-on-black (`#ffff00` on `#000000`) delivers 19.5:1 contrast, and white-on-black delivers 21:1.
- [x] **Zero Hardcoded Colors:** Automated gate (`tests/web/prefs/test_tokens.py`) proves all colors originate from CSS custom properties in `tokens.css`.
- [x] **Anti-FOUC Head Loader:** An inline head script executes before initial body paint on all modern screens, stamping `data-*` tokens instantaneously with zero flash of unstyled theme.

#### Dimension 5: Cognitive & Motor Accessibility (WCAG 2.2 Target, 2.5.5, 2.5.8)
- [x] **Target Size (Minimum 44×44px):** All buttons, inputs, links, and checkboxes satisfy `--min-touch-target: 44px`.
- [x] **Reduced Motion Support:** `@media (prefers-reduced-motion: reduce)` and `[data-motion="reduced"]` disable decorative transitions and reduce animations to 0.001ms.
- [x] **Plain Language & Reading Comfort:** Simple Mode (`[data-simple-mode="true"]`) and Line Focus guide (`[data-line-focus="true"]`) reduce visual noise for users with ADHD and dyslexia.
- [x] **No Timeouts or Forced Urgency:** The application never expires user sessions, never deletes entered text abruptly, and requires user confirmation before destructive actions (e.g. clearing the planner).
