## Feature: Task N3.1 Frontend Shell & Design System

### 5-Line Plan

4. **Shell Interactivity:** Add `web/js/shell.js` for keyboard-accessible sidebar collapse and mobile drawer toggling with focus management.
5. **Quality Verification:** Verify `./scripts/check.sh`, `tests/test_a11y_static.py`, and `scripts/smoke.sh` pass cleanly before shipping.

### 1. Goal & Non-Goals
- **Goal:** Rebuild the frontend shell from scratch in `web/` (preserving `web_old/` as backup) to establish a Gemini-inspired, warm, inclusive application shell per `docs/NEXT-STEPS.md` (§1, §2). It provides a collapsible responsive sidebar, top bar, a centered main content column (max 720px), design tokens in `web/css/tokens.css` driven by `data-*` attributes on `<html>`, an inline `<head>` loader script reading `wp.prefs.v1` before first paint to eliminate FOUC, and full WCAG 2.2 AA accessibility (44px touch targets, visible focus, skip links, aria-live).
- **Non-Goals:**
  - Building interactive Home screen cards logic or connecting all forms to APIs (Task N3.2).
  - Building the interactive questionnaire wizard / live preview (Task N3.3).
  - Building the settings / comfort modal or page (Task N3.4).
  - Building the browser-only library storage UI (Task N3.5).
  - Building the preferences engine logic in `web/js/prefs/` (owned by P2 in Task N2.1).
  - Modifying backend endpoints or schemas (`app/**` owned by P1).
  - Decorative animations, neon gradients, sparkle icons, pure matte-black backgrounds, or framework build steps (explicitly prohibited).

### 2. Design & Architecture
```
+-----------------------------------------------------------------------+
|  Skip Link: [Sari la conținut] (visible on keyboard focus)            |
+-------------------+---------------------------------------------------+
|                   |  Top Bar: [Meniu]  Titlu Pagină     [Setări/Confort]
| Sidebar (260px)   |---------------------------------------------------|
|                   |                                                   |
|  [+] Conversație  |             Main Column (max 720px)               |
|  [-] Acasă        |                                                   |
|  [-] Bibliotecă   |             Card Aerisit / Casă                   |
|  [-] Angajator    |             "Cu ce te pot ajuta astăzi?"          |
|  [-] Setări       |                                                   |
|                   |             [ Spațiu Acțiuni / Formular ]         |
|  (Recente)        |                                                   |
|                   |             Live Region: aria-live="polite"       |
+-------------------+---------------------------------------------------+
```

- **Sidebar:**
  - **Desktop:** Collapsible sidebar (260px expanded, 64px collapsed via `data-sidebar="collapsed"`). Contains logo, "+ Conversație nouă", "Acasă", "Bibliotecă", "Angajator", "Setări", and recent history placeholder. Every item has an SVG icon and a visible text label.
  - **Mobile (<768px):** Off-canvas drawer opened by a `<button id="btn-menu-toggle">` in the top bar with visible text "Meniu" + icon. Includes backdrop overlay, Esc-to-close handler, and traps/returns focus cleanly.
- **Top Bar:** Sticky header containing the drawer toggle on mobile / collapse toggle on desktop, current page heading, and a quick "Setări de confort" button.
- **Main Column:** Single centered content column (`max-width: 720px`, responsive margins, `padding: var(--space-lg)`).
- **Aesthetic Principles (Inclusive & Warm):**
  - No purple/neon gradients, no sparkle/star decoration emoji, no typing animations.
  - **Light Theme (Default):** Warm off-white background (`#fbfaf8`), clean white cards (`#ffffff`), dark charcoal text (`#1c1b1f`), warm professional blue primary (`#1a56db`).
  - **Dark Theme:** Dark grey/navy (`#121824`), card surface (`#1e293b`), soft light text (`#f8fafc`), accent blue (`#60a5fa`). Never pure #000000 on #ffffff.
  - **High Contrast Theme:** Pitch black (`#000000`), white text (`#ffffff`), yellow accent (`#ffff00`), meets WCAG AAA (>= 7:1).
  - Base font 18px (`1.125rem`), line-height 1.6, line length max ~70 characters.
  - Visible 3px focus rings on all interactive elements with high contrast.

### 3. Contracts & Interfaces
- **Design Tokens (`web/css/tokens.css`):** All styling driven by CSS variables and `data-*` attributes (`data-theme`, `data-text`, `data-spacing`, `data-contrast`, `data-motion`, `data-font`, `data-density`, `data-sidebar`).
- **Synchronous `<head>` Loader:** Read `wp.prefs.v1` from `localStorage` inside `try { ... } catch(e) {}` and set attributes on `document.documentElement` before first render tree build.
- **Navigation & Landmarks:** `<a href="#main" class="skip-link">Sari la conținut</a>`, `<nav aria-label="Navigare principală">`, `<main id="main">`, `<div id="status-live" class="sr-only" aria-live="polite"></div>`.
