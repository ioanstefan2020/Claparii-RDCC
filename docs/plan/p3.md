- **Shell Consistency:** Matches `web/index.html` and `web/welcome.html`. Uses collapsible desktop sidebar (260px expanded, 64px collapsed), off-canvas mobile drawer (<768px), and sticky top bar.
- **Controls Grouping:** Form controls are grouped into 3 semantic `<fieldset>` elements:
  1. *Aspect vizual și Contrast:* Theme (`system`, `light`, `dark`) and Contrast (`normal`, `high`).
  2. *Lizibilitate și Text:* Text size (`m`, `l`, `xl`), Line & Letter Spacing (`comfortable`, `roomy`), and Font family (`default`, `readable`).
  3. *Comportament Interfață:* Motion (`full`, `reduced`), Density (`full`, `focused`), Language (`ro`, `en`), and Default Sidebar (`open`, `collapsed`).
- **Reactive Live Preview:** A sticky `<aside class="settings-preview-aside">` that updates instantly on any setting adjustment. Contains:
  - Overrides badge: indicates whether current settings match questionnaire answers or contain manual overrides (`overrides.length`).
  - Active preferences badge list.
  - Realistic task preview card: heading, tag, formatted paragraph, and primary button.
- **Dual Reset Architecture:**
  - *Button 1 ("Re-aplică răspunsurile din chestionar"):* Invokes `resetToAnswers(loadPrefs())`. Clears `overrides` array, recalculates preferences from questionnaire answers, saves to `localStorage`, applies to `<html>`, refreshes dropdowns, and triggers an aria-live announcement.
  - *Button 2 ("Resetează tot la valorile inițiale"):* Requires explicit confirmation. Opens an inline confirmation card (`#confirm-reset-box`, `role="alertdialog"`) with focus placed on "Anulează". Confirming invokes `resetAll()`, saves defaults to `wp.prefs.v1`, clears overrides, and re-applies defaults.
- **Export & Import (JSON):**
  - *Export:* Invokes `exportPrefsJson()` and generates a browser download for `primazi-preferinte.json` using an ephemeral `Blob` and object URL.
  - *Import:* Hidden file input `<input type="file" id="input-import-json" accept=".json,application/json">` triggered by an accessible button. Reads file with `FileReader`, calls `importPrefsJson(jsonString)`, validates against safe defaults via `migrate`, persists, applies attributes, and refreshes the page state with live announcement.

6. Clicking "Start over" (`#btn-reset-all`) opens an accessible confirmation dialog; confirming resets `wp.prefs.v1` to factory defaults via `resetAll()`, clears overrides, and resets UI controls.
7. Clicking "Exportă preferințele" downloads a valid JSON file named `primazi-preferinte.json` matching the `wp.prefs.v1` schema.
8. Selecting a JSON file via "Importă preferințe" parses the JSON via `importPrefsJson`, validates against defaults, saves to `localStorage`, and updates the UI instantly.

### 6. Risks & Fallbacks
1. **Risk:** Browser disables `localStorage` or runs in private mode with quota errors.
   - **Fallback:** `web/js/prefs/storage.js` implements `isUsingMemoryFallback()`. The settings page detects this and shows an accessible note: "Navighezi în mod privat: setările sunt păstrate activ doar în această sesiune." No crash occurs.
2. **Risk:** User imports a corrupted or malformed JSON file.
   - **Fallback:** `importPrefsJson` passes parsed object through `migrate()`, replacing invalid or corrupt fields with safe defaults. If JSON parsing throws a syntax error, a `try/catch` block catches the exception, displays an accessible error toast, and preserves existing settings untouched.
3. **Risk:** Accidental reset erases custom user configuration.
   - **Fallback:** Destructive action "Start over" requires explicit confirmation via an inline confirm box with focus directed to the Cancel button, preventing accidental triggers.

```
+-----------------------------------------------------------------------+
|  Skip Link: [Sari la conținut] (visible on keyboard focus)            |
+-------------------+---------------------------------------------------+
|                   |  Top Bar: [Meniu]  Titlu Pagină     [Setări/Confort]
| Sidebar (260px)   |---------------------------------------------------|
|                   |                                                   |
|  [+] Conversație  |             Main Column (max 720px)               |

|                   |             [ Spațiu Acțiuni / Formular ]         |
|  (Recente)        |                                                   |
|                   |             Live Region: aria-live="polite"       |
+-------------------+---------------------------------------------------+
```

- **Sidebar:**
  - **Desktop:** Collapsible sidebar (260px expanded, 64px collapsed via `data-sidebar="collapsed"`). Contains logo, "+ Conversație nouă", "Acasă", "Bibliotecă", "Angajator", "Setări", and recent history placeholder. Every item has an SVG icon and a visible text label.
  - **Mobile (<768px):** Off-canvas drawer opened by a `<button id="btn-menu-toggle">` in the top bar with visible text "Meniu" + icon. Includes backdrop overlay, Esc-to-close handler, and traps/returns focus cleanly.
- **Top Bar:** Sticky header containing the drawer toggle on mobile / collapse toggle on desktop, current page heading, and a quick "Setări de confort" button.
- **Main Column:** Single centered content column (`max-width: 720px`, responsive margins, `padding: var(--space-lg)`).
- **Aesthetic Principles (Inclusive & Warm):**
  - No purple/neon gradients, no sparkle/star decoration emoji, no typing animations.
  - **Light Theme (Default):** Warm off-white background (`#fbfaf8`), clean white cards (`#ffffff`), dark charcoal text (`#1c1b1f`), warm professional blue primary (`#1a56db`).
  - **Dark Theme:** Dark grey/navy (`#121824`), card surface (`#1e293b`), soft light text (`#f8fafc`), accent blue (`#60a5fa`). Never pure #000000 on #ffffff.
  - **High Contrast Theme:** Pitch black (`#000000`), white text (`#ffffff`), yellow accent (`#ffff00`), meets WCAG AAA (>= 7:1).
  - Base font 18px (`1.125rem`), line-height 1.6, line length max ~70 characters.
  - Visible 3px focus rings on all interactive elements with high contrast.

### 3. Contracts & Interfaces
- **Design Tokens (`web/css/tokens.css`):** All styling driven by CSS variables and `data-*` attributes (`data-theme`, `data-text`, `data-spacing`, `data-contrast`, `data-motion`, `data-font`, `data-density`, `data-sidebar`).
- **Synchronous `<head>` Loader:** Read `wp.prefs.v1` from `localStorage` inside `try { ... } catch(e) {}` and set attributes on `document.documentElement` before first render tree build.
- **Navigation & Landmarks:** `<a href="#main" class="skip-link">Sari la conținut</a>`, `<nav aria-label="Navigare principală">`, `<main id="main">`, `<div id="status-live" class="sr-only" aria-live="polite"></div>`.
